# GRT reference results

Results of the original Gordon's Reloading Tool (`2021.2030-NIGHTLY`) for the fixture loads in
`packages/formats/test/fixtures/`, captured with [`tools/grt-capture`](../../../../../tools/grt-capture/).
One file per load, named after it. Format: `GrtReference` in `tools/grt-capture/capture.ts`.

These are simulation outputs, not load data. They are used to check that the "GRT Traditional" engine
reproduces GRT; they say nothing about whether a load is safe.
